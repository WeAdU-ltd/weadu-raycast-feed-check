# WeAdU Feed Check

Raycast command that audits a pasted Google Shopping feed on the machine. It does not replace UTM Campaign Builder, already in the Raycast Store.

Before a pull request to `raycast/extensions`:

1. Set `author` in `package.json` to the Raycast handle Jeff uses.
2. Replace `assets/icon.png` if the placeholder is not the mark to publish.
3. Run `npm install` and `npm run typecheck` on a machine with the Raycast API package.

This folder does not open that pull request.

# Textes du Raycast Store (français, pour référence)

Le Raycast Store est en anglais : ces textes servent de référence et pour les communautés francophones.

## Titre

WeAdU Feed Check

## Description

Vérifie un flux Google Shopping collé : titre, GTIN, prix, image et lien manquants. Tout reste en local.

## Commande

- Titre : Check Shopping Feed
- Description : vérifier un flux Google Shopping collé

## Catégories

Productivity, Data

## Description longue

Collez un flux Google Shopping (RSS, Atom, CSV ou fichier séparé par des tabulations) et obtenez les problèmes de chaque produit : champs obligatoires vides, titres trop longs ou trop courts, GTIN dont la clé de contrôle est fausse, prix nuls ou sans devise, identifiants en double. Jusqu'à 500 produits par vérification. Les constats d'un produit se copient en une action.

La vérification se fait sur votre ordinateur. Aucune requête réseau, aucune connexion à un compte, aucune collecte de données. Un produit sans constat n'est pas validé pour autant par Google.

Gratuit et open source (licence MIT), conçu par WeAdU. L'interface est en anglais.

# Publication kit: WeAdU Feed Check (Raycast)

Texts for the WeAdU team member who posts by hand. Nothing here is posted automatically.

| File | Content |
| --- | --- |
| `listing-en.md` | Raycast Store texts in English (title, description, command). |
| `listing-fr.md` | The same texts in French, for reference. |
| `post-en.md` | Short announcement for the Raycast community, ready to copy. |
| `post-fr.md` | French version of the announcement. |
| `instructions-maricar.md` | Where to post, the rules to follow, and how to handle replies (English and French). |
| `checklist.md` | What has to be done before anything is posted. |

Do not post anything until the WeAdU team confirms that the extension is live in the Raycast Store and sends the Store link. Replace `LINK` with that link.
